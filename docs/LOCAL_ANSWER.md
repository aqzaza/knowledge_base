# 桌面本地回答

回答模式提供：仅检索、本地回答（Qwen3）、DeepSeek（付费）。默认仅检索。
本地模式不需要API Key，不调用DeepSeek，不自动下载任何文件。

当前需要手动安装的文件：
- runtime/llama-bin/llama-server.exe，以及同一个Windows CPU运行包中的DLL。
- GPU 可选：runtime/llama-cuda13/llama-server.exe，以及同一版本完整运行包和配套 CUDA DLL。
- models/qwen3-4b-gguf/Qwen3-4B-Q5_K_M.gguf。

本地流程先检索Top3，按本次顺序分配[1]等引用，将完整片段交给Qwen3。
这是固定RAG，不是本地Agent。DeepSeek模式仍保留模型自主工具调用。
答案显示在回答页，原文显示在检索证据页；编号有效不代表语义支持正确。

本地模式的“推理设备”提供自动（优先 GPU）、GPU（CUDA 13）、CPU。
自动选择仅在没有CUDA引擎时使用CPU；已选择CUDA但失败时明确提示，不自动重试。
CUDA请求加载99层，引擎按实际模型层数和可用显存处理；根据实际推理日志确认
至少一层已加载到GPU才显示CUDA，并展示真实层数。部分层在GPU也会报告实际数量。
只有运行包文件存在或指定了GPU参数不算加速成功。
GPU失败可手动选择CPU，CPU使用原runtime/llama-bin，不回退付费API。
这只控制Qwen3，不改变BGE-M3已有的自动设备选择。
Qwen3使用6线程、4096上下文、最多512生成tokens、非思考模式。
第一次本地提问后台启动 llama-server 并加载模型；后续同设备提问复用该进程，
不再每问加载一次。每问只发送当前问题和证据，没有多轮聊天历史。
模型加载与单次回答各有180秒等待上限；缺失模型、DLL、内存不足或无输出时提示失败并保留证据，
不会自动回退到云端。查询期间暂不支持取消，关闭窗口需要等待任务结束。
切换推理设备、离开本地回答模式、修改材料、更新材料库、切换检索模型及正常关闭窗口时，
停止窗口拥有的进程并释放Qwen3占用的内存/显存；下次本地提问重新加载。
更新材料库前释放Qwen3以减少与Embedding编码的显存竞争，不保证所有材料规模都无显存不足。
服务仅监听127.0.0.1动态端口，使用随机会话凭证，禁用网页与内置Agent工具。
桌面直接发送本机HTTP请求，不使用系统代理或跟随重定向；这不是云端API，不需要用户Key。
不再写临时提示词文件；进程日志实时读取并丢弃，只保留GPU层数，不保存正文或凭证。
主程序被强行结束或系统异常退出时尚不保证自动清理子进程；可在任务管理器结束对应
llama-server进程。不要将模型或运行包提交到GitHub；发布时保留许可证。

本轮65项离线测试通过，并实际完成自编证据的本地接口回答：
青竹、林晓、300元及有效[1]引用。不代表复杂资料准确率或本地Agent已验收。
桌面真实验收：导入材料并更新材料库，选择本地回答，API Key留空，提问后检查
结论和引用。切回仅检索不会启动Qwen3；DeepSeek必须填写自己的Key。

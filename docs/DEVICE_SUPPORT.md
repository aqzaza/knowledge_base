# CPU 与 GPU 兼容

程序根据 PyTorch 的 CUDA 可用性自动选择设备：可用时选择 CUDA，否则选择 CPU。
桌面材料管理的就绪状态显示实际运行设备。查询向量和材料向量使用相同设备，
缓存恢复会把保存的数值向量放到当前模型设备；CPU/GPU之间无需人为删除缓存。

没有 NVIDIA GPU、未安装 CUDA 驱动或使用 CPU 版 PyTorch 的用户可以在 CPU 上运行。
CPU 仍需足够内存和本地模型文件；本功能不会自动下载模型或安装驱动。
CUDA 可用但显存不足或驱动运行失败时会报错，不承诺所有 GPU 故障都能自动恢复。
后端 load_index 支持显式 device="cpu" 以便验证；桌面目前自动选择，没有设备切换控件。

模型存放在程序源码目录的 models/<模型名>/。至少需要 config.json 和主权重
model.safetensors 或 pytorch_model.bin，以及对应分词器、Sentence Transformers
配置等文件。缺失或无法加载时桌面提示模型名称与处理方向，不联网补齐。
发布版外部模型路径将在打包阶段统一处理，不应将大型模型误提交到 GitHub。

默认仍为 BGE-M3。较轻的 E5-small 可用于兼容验证，但已有开发题对照显示其中文
检索不足，不能因为速度快就宣称同等效果。CPU运行速度因硬件和材料规模而异。

本轮验证：60项离线测试通过，覆盖自动CPU/CUDA选择、缺失模型和加载错误提示。
用现有 E5-small 在 CPU 实际完成一份自编测试材料的编码、检索及缓存恢复，
向量形状(1,384)，设备cpu。没有下载或API调用；未在另一台无GPU电脑验收，
也未重复实际BGE-M3的CPU编码或CUDA编码。

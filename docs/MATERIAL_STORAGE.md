# 本地材料保存

桌面每次追加、移除或清空材料时自动保存，启动时恢复文件名和抽取后的正文。
保存路径在材料管理页显示，Windows 通常为：
`%LOCALAPPDATA%/AIResearchAssistant/materials.json`。
使用 Qt 的用户数据目录，不写到程序安装目录或仓库中。

保存的是明文 JSON 文本副本，不是原始 Word/Excel 文件或完整文件路径。
新增材料会保存导入路径的 SHA-256 标识，用于重启后识别重复导入；
这不是正文加密或内容去重。旧版没有该标识的材料仍能直接读取，不自动改写旧文件。
原文件移动或内容改变不会自动同步，需要移除后重新导入。
不会保存 API 密钥、答案或模型对象。向量索引另存为同目录的 index.npz，
首次建索引后自动保存；重启自动恢复所用模型并在后台加载模型、校验缓存。
材料、模型文件、依赖版本、切分规则未变时直接恢复向量，不重新编码材料。
模型本身仍需从本地加载，完成后才能查询；若缓存无效则重新构建。
旧版本只保存过材料而没有索引缓存，需要在新版中手动建立一次。
移除和清空仅更新本地副本，不删除原文件；材料修改成功后删除旧向量缓存。
索引缓存保存失败不影响本次内存查询，但会明确提示下次仍需重建。
缓存使用数值数组，不使用 pickle；本地模型变更按文件尺寸与修改时间识别。

采用 QSaveFile 原子提交；失败时原材料和内存列表保留，本次修改不生效。
损坏或超限的保存文件不会自动覆盖，界面提示路径；请先备份后修复或移走
该文件，再重启程序。保存内容按文件数量、大小、格式与同名限制校验。

材料库最多 500 份，原始文件总大小最多 20 MiB，抽取正文的 UTF-8 总量最多 20 MiB；
单文件读取仍最多 1 MiB，保存文件本身最多 128 MiB（包含 JSON 转义开销）。
这只是保护上限，不代表已验证所有 500 文件组合的性能。

## 文件夹与同名来源

“导入文件夹”递归选择 TXT、MD、DOCX、XLSX，不运行其中代码。
跳过隐藏子目录和子项中的符号链接/目录联接；扫描最多 10000 个条目。
支持文件超过 500 份或扫描超限时整次扫描拒绝，原材料不变。
正常导入仍逐项处理坏文件；有效材料只有成功保存后才加入当前材料库。

不同目录的同名文件可以共存，例如 `index.md` 和 `index (chapter_attention).md`；
显示名称只用于材料库及证据来源，原文件不会改名。名称仍碰撞时加序号。
重复导入同一路径的文件会拒绝，包括重启后；修改正文后需要先移除旧材料。
文件移动到另一路径会被视为新的导入来源，不根据正文相同就删除或合并材料。
旧版缺少路径标识时，同名且正文相同的导入会保守拒绝，避免意外重复；
原先已保存的来源名称和有效缓存保持原有兼容规则。

当前仅支持单个程序窗口管理同一材料库；不要同时打开多个实例修改资料。
本地副本没有加密，勿将该目录加入 Git 或发布包；关闭程序不会删除它。
如需移除所有副本，使用材料管理中的“清空材料”。

## 验收

1. 导入两份材料并建立索引，关闭重开；等待模型加载后显示“已恢复缓存，未重新编码”，可以直接查询。
2. 移除一份，再重开，只剩另一份，原文件仍然存在。
3. API 设置的密钥始终不随材料恢复。

# 桌面 API 设置

在“API 设置”页填写自己的 API Key、模型名和 HTTPS 接口地址。
模型默认 deepseek-flash，地址默认 https://api.deepseek.com。
填写配置不验证密钥、不发送请求；只有明确勾选 DeepSeek 并点击查询时才调用。

密钥隐藏显示，仅保存在当前程序内存中，不写入配置文件；重启后重新填写。
“清除密钥”清空当前输入。Python/Qt 不保证安全擦除内存，所以不要将本功能描述为
加密密钥存储。调用期间不能修改配置；调用结束后后台任务释放其配置引用。
桌面 Agent 不读取 .env 或 DEEPSEEK_API_KEY 环境变量，不回退到开发者密钥。

自定义接口地址会接收你的密钥及模型请求内容，务必使用可信服务。
资料片段与问题会发送给该接口，不应导入不允许向服务商发送的敏感材料。
仅支持当前 ChatDeepSeek 客户端兼容的服务，不保证任意模型接口可用。

发布检查：源码、安装包和 GitHub Release 中不得包含 .env、真实密钥或私人资料。
.gitignore 是防止误提交的辅助措施，不保证打包工具不会包含 .env。
embed_query.py 的 CLI 实验仍使用原本的环境配置；发布桌面版时不要打包 .env。

手动验收：不填写密钥且勾选 DeepSeek，查询应跳转 API 设置并提示填写；
填写自己的密钥后可查询；取消 DeepSeek 可继续本地检索；关闭重开后密钥为空。
